# CardioPulse AI 🫀

CardioPulse AI is an advanced clinical decision support system designed to analyze patient health parameters and evaluate cardiovascular risk using machine learning models. The system combines a robust Flask backend with a modern React frontend featuring a Midnight Slate UI to provide interactive predictions, telemetry, data insights, and visual dashboards.

## Project Overview

- The application takes essential clinical parameters such as age, biological sex, chest pain type, resting blood pressure, cholesterol, maximum heart rate, exercise-induced angina, and other biomarker features as input.
- Supervised machine learning models analyze these parameters to generate a real-time heart disease risk assessment along with confidence metrics.

## Key Features

- Cardiovascular risk evaluation using Machine Learning
- Interactive clinical parameter input form
- Risk classification and confidence metrics
- Clinical analytics hub and telemetry dashboard
- Patient age and biomarker distribution visualizations
- Algorithm benchmark and feature importance analysis
- Modern Midnight Slate UI design optimized for medical workflows
- REST API using Flask and React frontend

## Machine Learning Models

The project utilizes:
- Logistic Regression
- Random Forest Classifier

The dataset is partitioned into training and testing sets using an 80:20 split, with feature scaling performed using `StandardScaler` prior to model training.

## Dataset Overview

The dataset contains 1,025 patient records with 13 health-related features and one target prediction variable:

### Input Features
1. **Age:** Age in years
2. **Sex:** Biological sex (1 = Male, 0 = Female)
3. **Chest Pain Type (cp):** Angina classification (0-3)
4. **Resting Blood Pressure (trestbps):** Measured in mmHg
5. **Serum Cholesterol (chol):** Measured in mg/dl
6. **Fasting Blood Sugar (fbs):** > 120 mg/dl indicator
7. **Resting ECG (restecg):** Electrocardiographic results
8. **Maximum Heart Rate (thalach):** Peak heart rate achieved
9. **Exercise-Induced Angina (exang):** Presence of angina
10. **ST Depression (oldpeak):** Induced by exercise relative to rest
11. **Slope:** Peak exercise ST segment slope
12. **Major Vessels (ca):** Number of major vessels colored by fluoroscopy
13. **Thalassemia (thal):** Blood flow defect profile

### Target Variable
- **0:** Normal / Low Risk Profile
- **1:** Positive Cardiovascular Risk Profile

### How the System Works
User inputs clinical telemetry parameters via the React frontend.

The request is transmitted to the Flask REST API.

Data undergoes preprocessing and scaling.

Trained machine learning models evaluate the metrics.

The system outputs the diagnostic risk classification and confidence score, rendered instantly on the dashboard.

### API Endpoints
The Flask backend exposes the following endpoints:

GET /api/health - Server health check

GET /api/statistics - Dataset statistics and telemetry

POST /api/predict - Executes cardiovascular risk evaluation

### Running the Project Locally
1. Clone the Repository

git clone [https://github.com/your-username/cardio-pulse-ai.git](https://github.com/your-username/cardio-pulse-ai.git)
cd cardio-pulse-ai
2. Start the Backend API

cd backend
pip install -r requirements.txt
python app.py
The Flask API will run locally at http://127.0.0.1:5000.

3. Start the Frontend
Open a new terminal window/tab:

npm install
npm run dev
The React development server will start locally.
